# 🎨 Kometa Config

Custom Kometa configs for curating your Plex library like a masterpiece. 🎬✨
This is less “just metadata” and more like your media library's personal stylist, interior decorator, and award-winning showrunner rolled into one.

## About this project

These configuration files are designed to work with **[Kometa](https://kometa.wiki/en/nightly/)**, an advanced metadata management tool for Plex Media Server. With this setup, you can:

- Create custom collections
- Apply advanced filtering and smart labeling
- Keep your library organized with recurring jobs
- Enhance your user experience with minimal effort

You can view or contribute to this project on [GitHub](https://github.com/scottgigawatt/kometa-config).

## Contents

- YAML-based Kometa config structure
- Examples for genre, actor, and theme-based collections
- Notes on scheduling and usage with Docker
