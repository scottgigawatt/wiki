# 🪼 Jellyfin Reef

Welcome to the **Jellyfin Reef**, where media swims free and subscription sharks can't bite. This Docker Compose setup lets you deploy your own streaming sanctuary on Synology NAS—or any system seaworthy enough to run containers.

## 🛟 What's Afloat?

This repository deploys [Jellyfin](https://jellyfin.org/) via Docker Compose. It's designed to manage your self-hosted movie and show collection like an elegant aquatic archive, swimming circles around paid platforms.

You can board the ship here: [GitHub](https://github.com/scottgigawatt/jellyfin)

Special thanks to [Marius Hosting](https://github.com/mariushosting) for guiding the early currents.
