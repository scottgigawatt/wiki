# 🛠️ Custom Scripts

Welcome to the Scripts vault—home of hacks, helpers, and more duct-tape magic than a hacker convention on open bar night.

## 🔍 What's Inside

A collection of scripts spanning multiple shells and platforms, written for utility, automation, and just a little chaos:

- 🐚 **Bash Scripts** – Cron-ready, sanity-saving shell scripts for daily ops
- 📜 **SH Scripts** – Portable classics that run anywhere Unix-ish
- 💠 **Zsh Scripts** – For the terminal maximalist who loves a bit of flair
- 🍎 **macOS Automator Workflows** – Your Mac, only smarter
- 🔧 **Miscellaneous Scripts** – Odds, ends, and gremlins of every kind

## ⚙️ How to Use

Each script comes with notes or inline comments to get you up and running. Pop one into your bin, add to cron, or tweak to taste.

## 👩‍🚀 Contribute Your Chaos

Have a script you love? Or improved one of mine? Fork, PR, and let the code spread like well-meaning wildfire.

You can view or contribute to this project on [GitHub](https://github.com/scottgigawatt/scripts).
