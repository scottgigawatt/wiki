# ☠️ Plundarr

Ahoy there! Welcome to **Plundarr**—where we hoist the Jolly Roger and sail the high seas of media automation! ⚓️
These be the scripts and cron-powered sorcery that keep yer Plex shipshape without ye liftin' a finger.

Whether ye be automatin' yer collections, cleanin' the barnacles off yer metadata, or runnin' nightly raids on stale watchlists, Plundarr's got ye covered like a kraken on a clipper.

## About this booty

This here be a collection of custom scripts written in the sacred tongues of Python, Bash, and occasionally foul curses. They're designed to run on a schedule—daily, weekly, or whenever the tides be right—to keep yer media empire runnin' smoother than a barrel o' rum on Sunday.

You can fork the treasure or drop yer own doubloons at [GitHub](https://github.com/scottgigawatt/plundarr), matey.

## What's in the hold

- 🪝 Scripted Kometa and PATTRMM runs
- 🧼 Metadata sweeps and cleanup tasks
- 🔁 Plex trigger actions and webhook mayhem
- ⚓️ Cron jobs with log output fit for a captain's logbook
- 🏴‍☠️ Optional flair, sass, and piracy (consensual, of course)

## Tools o' the Trade

- Bash
- Python
- Cron
- A black heart and a thirst for well-sorted media
